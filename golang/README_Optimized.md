## 🎯 概述

这是对原始`main.go`的全面优化重构，实现了《动态分区.md》文档中描述的完整算法方案。新版本采用模块化设计，提供更强大的功能和更好的可维护性。

### 主要改进

- ✅ **多阶段设计**: 严格按照文档的四阶段流程实现
- ✅ **约束处理**: 完善的时间窗口约束和负载均衡机制
- ✅ **启发式搜索**: 局部搜索 + 模拟退火全局优化
- ✅ **性能监控**: 详细的性能指标和约束状态监控
- ✅ **配置管理**: 统一的参数配置和灵活调整
- ✅ **错误处理**: 健壮的异常处理和日志记录
- ✅ **模块化**: 清晰的代码结构和职责分离

## 🚀 算法特性

### 1. 多阶段算法架构

```
第一阶段: 数据预处理与约束分析
├── 距离矩阵构建
├── 时间窗口约束分析  
├── 点位特征提取
└── 约束可行性验证

第二阶段: 基于地理位置的初始分区
├── K-means聚类初始化
├── 负载均衡调整
└── 时间窗口可行性验证

第三阶段: 启发式优化与局部搜索
├── 局部搜索优化
├── 模拟退火全局优化
└── 约束满足性维护

第四阶段: 结果验证与输出
├── 性能指标计算
├── 约束满足性检查
└── 结果格式化输出
```

### 2. 关键技术要点

- **多目标优化**: 平衡负载均衡、总距离、时间窗口约束
- **约束处理**: 软约束与硬约束分离处理
- **启发式搜索**: 多种邻域操作和搜索策略
- **算法复杂度优化**: 并行计算、缓存机制、增量更新

### 3. 补货点位优先级处理

- 优先分配补货点位到最优聚类中心
- 补货点位权重调整机制
- 补货点位数量均衡策略

## 🔄 算法流程

### 阶段1: 数据预处理与约束分析

```go
// 1.1 距离矩阵构建
alg.buildDistanceMatrix()

// 1.2 时间窗口约束分析
alg.analyzeTimeWindowConstraints()

// 1.3 点位特征提取
alg.extractPointFeatures()

// 1.4 约束可行性验证
alg.validateConstraintFeasibility()
```

**输出**: 标准化特征矩阵、约束关系图、可行性报告

### 阶段2: 基于地理位置的初始分区

```go
// 2.1 K-means聚类初始化
groups := alg.kmeansCluster()

// 2.2 负载均衡调整
groups = alg.balanceGroupLoad(groups)

// 2.3 时间窗口可行性验证
groups = alg.validateTimeWindowFeasibility(groups)
```

**输出**: 初始分区方案、负载均衡报告

### 阶段3: 启发式优化与局部搜索

```go
// 3.1 局部搜索优化
groups = alg.localSearchOptimization(groups)

// 3.2 模拟退火全局优化
groups = alg.simulatedAnnealingOptimization(groups)

// 3.3 约束满足性维护
groups = alg.maintainConstraintSatisfaction(groups)
```

**输出**: 优化后分区方案、收敛性分析

### 阶段4: 结果验证与输出

```go
// 4.1 性能指标计算
performance := alg.calculatePerformanceMetrics(groups)

// 4.2 约束满足性检查
constraints := alg.checkConstraintSatisfaction(groups)

// 4.3 结果格式化输出
alg.outputResults(result)
```

**输出**: 性能报告、约束状态、CSV文件、详细报告

## ⚙️ 配置参数

### 基础参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `NClusters` | 3 | 聚类组数 |
| `MaxIterations` | 100 | K-means最大迭代次数 |
| `MaxOptimIter` | 30 | 优化最大迭代次数 |
| `MinInterval` | 120.0 | 时间窗口最小间隔（分钟） |

### 距离权重参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `TimeWeight` | 0.7 | 行驶时长权重 |
| `GeoWeight` | 0.3 | 地理距离权重 |

### 优化参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `StdFactor` | 2.0 | 离群点判定标准差倍数 |
| `ThresholdKm` | 15.0 | 孤立点归组阈值（公里） |

### 模拟退火参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `InitTemp` | 100.0 | 初始温度 |
| `CoolRate` | 0.95 | 冷却率 |
| `MinTemp` | 0.1 | 最小温度 |

### 参数调整示例

```go
func createCustomConfig() *Config {
    config := DefaultConfig()
    
    // 调整聚类参数
    config.NClusters = 4        // 增加到4个组
    config.MaxIterations = 150  // 增加迭代次数
    
    // 调整权重
    config.TimeWeight = 0.8     // 更重视时间
    config.GeoWeight = 0.2      // 降低地理权重
    
    // 调整优化参数
    config.MaxOptimIter = 50    // 增加优化迭代
    config.InitTemp = 200.0     // 提高初始温度
    
    return config
}
```

### 常见问题

#### 1. 编译错误

```bash

# 解决：确保只运行一个主程序
go run dynamic_partition.go algorithm_impl.go main_optimized.go
```

#### 2. 数据文件问题

```bash
# 错误：无法读取数据文件
# 解决：检查文件路径和格式
```

#### 3. 内存不足

```bash
# 错误：out of memory
# 解决：减少聚类数量或数据规模
config.NClusters = 2  // 减少到2个组
```

#### 4. 性能问题

```bash
# 问题：执行时间过长
# 解决：调整算法参数
config.MaxIterations = 50      // 减少迭代次数
config.MaxOptimIter = 20       // 减少优化迭代
```

### 性能调优建议

#### 1. 数据规模优化

- 点位数量 < 500: 使用默认配置
- 点位数量 500-1000: 减少迭代次数
- 点位数量 > 1000: 考虑分批处理

#### 2. 算法参数调优

```go
// 小规模数据（< 200点位）
config.MaxIterations = 50
config.MaxOptimIter = 20

// 中等规模数据（200-500点位）
config.MaxIterations = 100
config.MaxOptimIter = 30

// 大规模数据（> 500点位）
config.MaxIterations = 150
config.MaxOptimIter = 50
```

#### 3. 硬件要求

- **最低配置**: 2GB RAM, 2核CPU
- **推荐配置**: 4GB RAM, 4核CPU
- **高性能配置**: 8GB RAM, 8核CPU
