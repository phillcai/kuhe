# 两阶段分配版本 (v2.0-two-stage)

## 概述

本版本在 v1.0-baseline 基础上实现了两阶段分配策略：
1. **第一阶段**：对补货点位进行聚类分组（保持不变）
2. **第二阶段**：将非补货点位按行驶时间最短原则分配到各组，允许30%的负载不均衡

## 核心改进

### 1. 配置增强
- 新增 `EnableSecondStage` 配置项：启用/禁用第二阶段分配
- 新增 `LoadBalanceTolerance` 配置项：负载均衡容忍度（默认30%）

### 2. 算法流程
```
数据预处理 → 补货点位聚类 → 非补货点位分配 → 启发式优化 → 结果输出
```

### 3. 关键实现
- **LoadData**: 支持两种模式（单阶段/两阶段）
- **SecondStageAssignment**: 实现第二阶段分配逻辑
- **calculateMinTravelTimeToGroup**: 计算点位到组的最短行驶时间
- **adjustLoadBalance**: 负载均衡调整（允许容忍度）

## 执行结果

### 数据统计
- **总点位数**: 99个
- **补货点位**: 40个
- **非补货点位**: 59个
- **分组数量**: 3个

| 分组 | 总点位数 | 补货点位数 | 非补货点位数 | 负载比例 |
|------|----------|------------|--------------|----------|
| 分组1 | 33个 | 13个 | 20个 | 33.3% |
| 分组2 | 32个 | 9个 | 23个 | 32.3% |
| 分组3 | 34个 | 18个 | 16个 | 34.3% |

### 性能指标
- **负载均衡指数**: 0.980 (优秀)
- **平均组大小**: 33.0个点位
- **负载差异**: 最大34个，最小32个 (6.25%差异，符合30%容忍度)
- **执行时间**: 0.06秒

## 技术特点

### 1. 距离计算策略
- **优先使用**: 实际路网行驶时长数据
- **备选方案**: 地理距离计算
- **容错处理**: 数据缺失时使用默认值

### 2. 负载均衡策略
- **容忍度控制**: 允许30%的负载不均衡
- **智能调整**: 从过载组向轻载组移动非补货点位
- **成本优化**: 选择移动成本最小的点位

### 3. 约束保持
- **补货点位分组**: 第一阶段结果保持不变
- **时间窗口约束**: 继续满足时间窗口要求
- **地理连续性**: 尽量保持分组的地理合理性
