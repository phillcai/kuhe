# 甜品饮料补货需求文档

## 1. 需求背景

甜品饮料之前没有完整的库存管理和动态补货系统，当前需要补齐这一功能，建立完整的库存管理和补货机制。

## 2. 核心功能需求

### 2.1 央厨车辆分拣补货

#### 2.1.1 补货触发条件
- 根据车辆未来需要补货的点位情况，按预估量计算需要补货的各SKU数量
  - 取车辆绑定点位未来 30 小时的缺货点位
- 当车上的数量不能满足需求时，车辆分拣需要执行补货操作

#### 2.1.2 补货策略
**饮料补货策略：**
- 按照整个标准架子替换方式补货
  - 架子可以放的箱子个数?
  - 有几种箱子? 和 sku 的映射关系? 每个箱子的规格数量?
- 架子的SKU数量按销量比例预估
- 按整箱计算补货数量

**甜品补货策略：**
- 按照缺货的数量向上取整到整箱
- 需要适度考虑冗余量
- 车上剩余的货保持不动
- 仅在周六时会回库清空

#### 2.1.3 车辆容量限制
- 大车和小车的最大箱子容量不同
- 具体容量数据待定，需要后续确认

### 2.2 点位分拣补货

#### 2.2.1 补货原则
- 甜品和饮料的补货原则是跟随盒菜补货随路补货
- 不做专门的甜品饮料补货配送

#### 2.2.2 补货触发条件
- 当甜品/饮料在点位分拣时，预估到下次补货期间有SKU库存小于等于0
- 则本次分拣需要执行补货操作

#### 2.2.3 货道管理
- 货道有数量和类型的限制
- 甜品和饮料只能补充到指定类型的货道
- 每次需要分拣补货时，默认所有分配的货道补满
- 货道数按SKU的销售数量占比进行分配

## 3. 技术实现要求

### 3.1 补货量计算
- 饮料：按标准架子容量计算
- 甜品：按缺货数量向上取整到整箱
- 考虑车辆容量限制

### 3.2 库存管理
- 周六回库清空流程

## 4. 待确认事项

1. 大车和小车的具体箱子容量数据
2. 标准架子的具体规格和容量
3. 各SKU的销量历史数据和预估模型
4. 货道类型和数量的具体限制
5. 冗余量的具体计算标准
