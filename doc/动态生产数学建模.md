# 央厨动态生产数学建模

## 一、核心参数定义

| 参数符号 | 含义说明 |
| ---- | ---- |
| $i$ | 菜品SKU标识（如sku1、sku2、sku3等） |
| $M_i$ | 菜品SKU $i$ 的最终生产数量（待求解） |
| $M$ | 总生产数量，$M = \sum M_i$ |
| $P_i^{prev}$ | 前天菜品SKU $i$ 的实际生产数量 |
| $S_i^{prev}$ | 昨天菜品SKU $i$ 的实际销售数量 |
| $D_i^{raw}$ | 菜品SKU $i$ 的原始调整量，$D_i^{raw} = P_i^{prev} - S_i^{prev}$ |
| $D_i^{status}$ | 菜品SKU $i$ 的入库状态：1=有入库数据，0=无入库数据 |
| $S_i^{status}$ | 菜品SKU $i$ 的销售状态：1=有销售数据，0=无销售数据 |
| $C_i^{status}$ | 菜品SKU $i$ 的生产计划状态：1=有明天生产计划，0=无明天生产计划 |
| $A_i$ | 菜品SKU $i$ 的可调整性指示函数：1=可调整，0=不可调整 |
| $r_i$ | 菜品SKU $i$ 的预期生产比例，满足 $\sum r_i = 1$ 且 $r_i \geq 0$ |
| $r_i^{fixed}$ | 不可调整菜品SKU $i$ 的固定比例 |
| $r_i^{adjust}$ | 调整后可调整菜品的比例，$r_i^{adjust} = \frac{r_i}{1 - \sum_{j: A_j=0} r_j^{fixed}}$ |
| $M_i^{base}$ | 菜品SKU $i$ 的基准生产量（根据生产计划状态确定） |
| $\Delta_i$ | 菜品SKU $i$ 的调整量（可正可负） |
| $\Delta_{total}^{redistribute}$ | 需要重新分配的总调整量 |
| $w_i$ | 菜品SKU $i$ 的重要性权重 |

## 二、状态分类与处理策略

根据明天生产计划、前天入库数据、昨天销售数据的存在情况，定义处理策略：

| 明天生产计划 | 前天入库数据 | 昨天销售数据 | 处理方式 | 数学表达式 |
| ---- | ---- | ---- | ---- | ---- |
| 有 | 没有 | 有 | 入库数据当做0处理 | $P_i^{prev} = 0, D_i^{raw} = 0 - S_i^{prev} = -S_i^{prev}$ |
| 有 | 没有 | 没有 | 新菜，不调整对应菜品生产计划，其他菜品等比例缩小 | $A_i = 0, M_i = M_i^{base}, \Delta_i = 0$ |
| 有 | 有 | 没有 | 销售数据当做0处理 | $S_i^{prev} = 0, D_i^{raw} = P_i^{prev} - 0 = P_i^{prev}$ |
| 没有 | 没有 | 有 | 其他菜品等比例放大 | $A_i = 0, M_i = 0$ |
| 没有 | 有 | 有 | 正常调整逻辑 | $A_i = 1, D_i^{raw} = P_i^{prev} - S_i^{prev}$ |
| 没有 | 有 | 没有 | 销售数据当做0处理 | $S_i^{prev} = 0, D_i^{raw} = P_i^{prev}$ |

## 三、约束条件定义

### 3.1 强约束（硬约束）

| 约束类型 | 约束表达式 | 含义说明 |
| ---- | ---- | ---- |
| 非负约束 | $M_i \geq 0$ | 生产数量不能为负 |
| 总量约束 | $M = \sum_{i} M_i$ | 总生产量为各SKU生产量之和 |
| 不可调整约束 | $A_i = 0 \Rightarrow M_i = M_i^{base}$ | 不可调整的菜品保持基准生产量不变 |
| 状态一致性约束 | $C_i^{status} = 0 \Rightarrow M_i = 0$ | 无生产计划的菜品生产量为0 |

### 3.2 弱约束（软约束）

| 约束类型 | 目标函数/优先级 | 含义说明 |
| ---- | ---- | ---- |
| 调整量最小化 | $\min \sum_{i: A_i=1} w_i \cdot |\Delta_i|$ | 最小化总调整量，优先级：高 |
| 比例平衡约束 | $\min \sum_{i,j} \left\| \frac{M_i}{M_j} - \frac{r_i^{adjust}}{r_j^{adjust}} \right\| \times r_j^{adjust}$ | 可调整菜品的生产比例接近预期比例，优先级：中 |
| 产能利用率 | $\max \frac{M}{M^{capacity}}$ | 最大化产能利用率，优先级：低 |

## 四、调整量分配策略

### 4.1 可调整性判断

定义菜品可调整性：
$$A_i = \begin{cases} 
1 & \text{if } C_i^{status} = 0 \text{ and } (D_i^{status} = 1 \text{ or } S_i^{status} = 1) \\
0 & \text{otherwise}
\end{cases}$$

### 4.2 基准生产量确定

根据生产计划状态确定基准生产量：
$$M_i^{base} = \begin{cases}
M_i^{plan} & \text{if } C_i^{status} = 1 \text{（有明天生产计划）} \\
0 & \text{if } C_i^{status} = 0 \text{（无明天生产计划）}
\end{cases}$$

### 4.3 原始调整量计算

计算每个菜品的原始调整需求：
$$D_i^{raw} = \begin{cases}
P_i^{prev} - S_i^{prev} & \text{if } D_i^{status} = 1 \text{ and } S_i^{status} = 1 \\
-S_i^{prev} & \text{if } D_i^{status} = 0 \text{ and } S_i^{status} = 1 \\
P_i^{prev} & \text{if } D_i^{status} = 1 \text{ and } S_i^{status} = 0 \\
0 & \text{otherwise}
\end{cases}$$

### 4.4 调整量重分配机制

**步骤1：计算不可调整菜品的固定调整量**
$$\Delta_{fixed} = \sum_{i: A_i=0} D_i^{raw}$$

**步骤2：计算可调整菜品的有效比例**
$$r_i^{adjust} = \frac{r_i}{\sum_{j: A_j=1} r_j}, \quad \forall i: A_i = 1$$

**步骤3：分配调整量给可调整菜品**
$$\Delta_i = \begin{cases}
D_i^{raw} - \Delta_{fixed} \times r_i^{adjust} & \text{if } A_i = 1 \\
D_i^{raw} & \text{if } A_i = 0
\end{cases}$$

## 五、优化目标函数

采用分层优化策略：

### 5.1 第一层：满足硬约束
确保所有强约束得到满足。

### 5.2 第二层：多目标优化
$$\min \quad F = \alpha \cdot F_{adjustment} + \beta \cdot F_{proportion} + \gamma \cdot F_{utilization}$$

其中：
- $F_{adjustment} = \sum_{i: A_i=1} w_i \cdot |\Delta_i|$ （调整量惩罚项）
- $F_{proportion} = \sum_{i,j: A_i=A_j=1} \left| \frac{M_i}{M_j} - \frac{r_i^{adjust}}{r_j^{adjust}} \right| \times r_j^{adjust}$ （比例偏差项）
- $F_{utilization} = |M^{target} - M|$ （与目标产能的偏差）
- $\alpha, \beta, \gamma$ 为权重系数，建议 $\alpha = 0.6, \beta = 0.3, \gamma = 0.1$

## 六、算法执行步骤

### 步骤1：数据预处理
1. 识别各菜品的状态：$C_i^{status}, D_i^{status}, S_i^{status}$
2. 计算原始调整量：$D_i^{raw} = P_i^{prev} - S_i^{prev}$
3. 确定可调整性：$A_i$
4. 设定基准生产量：$M_i^{base}$

### 步骤2：调整量重分配
1. **计算不可调整菜品的总调整量**：
   $$\Delta_{fixed} = \sum_{i: A_i=0} D_i^{raw}$$

2. **计算可调整菜品的有效比例**：
   $$r_i^{adjust} = \frac{r_i}{\sum_{j: A_j=1} r_j}, \quad \forall i: A_i = 1$$

3. **重分配调整量**：
   $$\Delta_i = \begin{cases}
   D_i^{raw} - \Delta_{fixed} \times r_i^{adjust} & \text{if } A_i = 1 \\
   D_i^{raw} & \text{if } A_i = 0
   \end{cases}$$

### 步骤3：最终生产量计算
$$M_i = \max(0, M_i^{base} - \Delta_i)$$

### 步骤4：约束验证与调整
1. 验证非负约束：$M_i \geq 0$
2. 验证总量约束
3. 必要时进行微调优化

### 步骤5：结果输出
输出最终的生产计划：$\{M_1, M_2, ..., M_n\}$

| E   | 40       | 30       | 25       | 0.1      | 可调整   | 正常调整 |
