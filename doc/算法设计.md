# 无人售货机配送路径规划——三种算法思路

## 1. 混合遗传算法（Hybrid Genetic Algorithm, HGA）
# 中文注释：
# 该算法结合了遗传算法的全局搜索能力和局部搜索（如贪心或局部优化）的精细调整能力，适合解决带时间窗和容量约束的复杂路径规划问题。
### 原理说明：
- 初始化种群，每个个体代表一组车辆配送路径。
- 采用交叉、变异等遗传操作生成新解。
- 在每一代中，对个体进行局部搜索（如2-opt、贪心插入等）优化。
- 适应度函数综合考虑补货点优先级、时间窗、车辆容量等约束。
- 迭代进化，最终输出最优或近优解。

## 2. 带时间窗的节约算法（Savings Algorithm with Time Windows）
# 中文注释：
# 该算法基于经典的节约算法（Clarke-Wright Savings），通过合并路径节约成本，并在合并过程中动态检查时间窗和容量约束。
### 原理说明：
- 初始时每个点位单独一条路径。
- 计算所有点对的节约值（合并两条路径可节省的距离/时间）。
- 按节约值从大到小尝试合并路径，合并时检查是否满足时间窗和车辆容量。
- 直到无法继续合并为止，输出最终路径。

## 3. 基于优先级的贪心插入法（Priority-based Greedy Insertion）
# 中文注释：
# 该算法先对所有点位按缺货风险、销量等设定优先级，然后采用贪心策略将高优先级点位依次插入到当前最优路径中。
### 原理说明：
- 计算每个点位的补货优先级。
- 初始化路径为空，依次选择优先级最高且可行（不违反时间窗和容量）的点位插入路径。
- 若当前车辆容量不足或时间窗冲突，则开启新路径或跳过该点位。
- 直到所有可补货点位分配完毕。
