# 软件开发岗位招聘

## 1. 软件架构师（Software Architect）

### 岗位职责

1. 负责公司智能设备软件系统的整体架构设计与技术选型
2. 根据产品迭代需求，设计系统的模块划分、接口协议、数据库结构，确保可扩展性与高可用性
3. 主导核心功能的技术攻关与关键代码开发，保障业务场景的稳定性
4. 建立软件开发规范（编码、测试、文档），推动CI/CD流程与质量体系落地
5. 指导和培养软件研发团队成员，提升团队整体技术水平
6. 关注前沿技术，结合业务需求探索云原生、AI算法在智能设备中的应用

### 任职要求

#### 1. 学历与经验
- 本科及以上学历，计算机、软件工程、自动化相关专业
- 5年以上软件研发经验，2年以上架构设计经验

#### 2. 技术能力
- 熟悉常见软件架构模式（微服务架构、服务治理、分布式事务处理）
- 有算法和大数据处理基础（深度理解图论算法、优化算法、机器学习算法及数仓相关基础）
- 熟悉 C/C++/Python/Go/Java 等至少两种语言
- 有物联网平台/物流系统相关经验者优先
- 熟悉云原生技术，熟练掌握Linux/Docker/K8s、云平台（AWS/阿里云）等优先

#### 3. 业务理解
- 具备硬件+软件结合的系统思维，能快速理解自动化设备运行逻辑

#### 4. 沟通与协作
- 具备良好的跨部门协作能力，能与硬件、产品、运营团队高效沟通

#### 5. 创业心态
- 适应快节奏的迭代环境，具备解决问题与推动落地的执行力

### 加分项

- 有过智能硬件/自动化设备/IoT平台的完整项目经验
- 熟悉海外市场支付、运营平台接口（如Stripe、AWS IoT、阿里云物联网等）
- 英语可作为工作语言，能直接对接海外团队

### 发展机会

- 直接参与公司核心智能设备产品的软件架构与技术演进
- 有机会成为技术负责人，主导公司技术发展方向
- 参与公司技术体系建设和团队成长

## 2. 软件全栈工程师（偏后端方向）

### 岗位职责

1. 参与公司智能设备运营平台的后端系统设计与开发（如设备管理、远程运维、支付/订单、用户管理模块）
2. 负责核心业务逻辑、API接口、数据库设计及性能优化
3. 协同前端和硬件团队，完成设备端与云端的数据交互与接口集成
4. 参与系统架构优化，提升系统的可扩展性、稳定性与安全性
5. 支持平台在海外市场的落地，处理本地化接口、支付方式与合规需求
6. 根据产品需求，快速完成功能开发并迭代上线

### 任职要求

#### 1. 基本要求
- 本科及以上学历，计算机、软件工程相关专业
- 2年以上后端研发经验

#### 2. 技术技能
- 精通 Python/Go/Node.js 中至少一种后端语言，有实际项目经验
- 熟悉数据库设计与优化（MySQL/PostgreSQL/Redis等），具备数据建模经验
- 了解前端基础（Vue/React/TypeScript等），能配合前端完成接口联调
- 有Linux开发经验，熟悉常见云服务（AWS/Azure/阿里云）及容器化（Docker/K8s）者优先

#### 3. 综合能力
- 英语读写良好，能阅读技术文档，具备跨团队沟通能力
- 具备创业心态，能适应快节奏与多任务环境，愿意在早期产品迭代中主动承担责任
- 对数据敏感，能够运用相关工具进行数据分析
- 了解推荐系统算法，有相关理论或实践经验者优先
  

### 加分项

- 有物联网/智能硬件后台系统经验
- 能完成基础的 web 页面开发
- 对 AI 辅助编程有较多实践经验

### 发展机会

- 直接参与公司核心智能设备的运营平台开发
- 技术广度与深度均有发展机会，可向后端技术专家或全栈方向成长
- 随着公司业务扩展，有机会承担小团队管理角色
