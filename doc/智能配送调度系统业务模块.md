# 智能配送调度系统业务模块

## 业务核心优化目标与约束说明

### 1. 优化目标

- **首要目标：最大化补货点位数**  
  优先保证在有限资源下，尽可能多地完成无人售货机点位的补货任务，提高整体服务覆盖率。

- **次要目标：最大化补货数量**  
  在满足补货点位数最大化的前提下，进一步提升补货商品的总数量，减少缺货风险。

- **成本综合最小化**  
  综合考虑配送成本（如车辆行驶距离/时间、人工等）与wastage（过量补货导致的损耗）成本，优化整体运营效益。

## 2. 车辆管理模块

### 2.1 排班配置

- 支持车辆、司机的班次排班，当前以配置的信息简化。

### 2.2 点位分拣

- 优化目标：根据当前班次的补货点位和各点位的销售预估，智能生成合理的分拣清单，兼顾补货点位数和补货总量。

### 2.3 动态区域划分

- 根据点位分布、订单量等，动态划分配送区域。
- 区域个数根据车辆排班确定。
- 不支持跨区配送。

### 2.4 路径规划

#### 2.4.1 人工运营
- 支持运营人员手动调整和优化配送路径。

#### 2.4.2 动态规划
- 基于实时数据召回补货点位后动态生成配送路径。

#### 2.4.3 顺路规划
- 优先选择顺路点位，约束条件是最小补货量。
- 考虑虚拟点位的技术设计。

## 3. 点位管理模块

### 3.1 销量预测

- 基于历史销售数据、节假日等因素，智能预测各点位未来销量，小时级别。
- 预测结果可视化。

### 3.2 库存信息

- 实时采集和监控各点位库存状态。
- 支持库存预警、缺货提醒。

### 3.3 运营管理

- 点位基础信息维护。
- 点位运营状态监控。
