# 智能配送调度系统 - 点位分拣需求与逻辑文档

## 1. 系统概述

点位分拣系统是智能配送调度系统的核心模块，负责根据点位需求、销量预测、库存情况等多维度数据，智能计算每个点位的商品补货量，并生成分拣单，确保配送效率和库存合理性。

## 2. 业务需求

### 2.1 核心目标
- **精准补货**：根据销量预测和历史数据，精准计算每个点位的补货需求
- **库存优化**：避免库存积压和缺货，提高商品周转率
- **效率提升**：通过智能分拣算法，提高配送和补货效率
- **成本控制**：减少不必要的补货成本和损耗

### 2.2 业务场景
- **日常补货**：基于销量预测的常规补货
- **全量补货**：营销活动或新开点位的满容量补货
- **应急补货**：库存不足时的紧急补货
- **特殊补货**：节假日、促销等特殊场景的补货

## 3. 数据模型与输入参数

### 3.1 核心输入参数
- **商品ID列表**：需要分拣的商品范围 (`commodity_type = 1` 主食)
- **目标点位ID**：分拣的目标点位
- **车辆ID**：执行配送的车辆，关联中央厨房库存

### 3.2 关键数据源
- **点位基础信息**：点位容量、设备类型、营业时间等
- **销量预测数据**：未来5天120小时的分时销量预测
- **历史销量数据**：过去7天的平均销量
- **库存数据**：点位当前库存、中央厨房库存
- **菜品评分数据**：基于历史销售比重的商品评分
- **特殊配置**：全量补货点位、营销活动等

## 4. 核心计算逻辑

### 4.1 点位补货量计算

#### 4.1.1 点位最大库存配置
```
- 设备类型1：108盒
- 点位ID=55：72盒  
- 其他点位：96盒
```

#### 4.1.2 销量预测逻辑
- **预测周期**：未来5天120小时
- **预测来源**：优先使用AI预测销量，缺失时使用历史平均销量
- **历史销量计算**：过去7天平均销量 × 5天，特殊点位(point_size=3)需乘以1.0系数

#### 4.1.3 补货量决策规则
```
IF 点位营业天数 <= 7天 THEN
    补货量 = 点位最大库存  // 新点位补满
ELSE IF 预测销量 > 点位最大库存 THEN  
    补货量 = 点位最大库存  // 高销量点位补满
ELSE
    补货量 = 预测销量  // 按预测销量补货
```

#### 4.1.4 特殊补货规则
- **全量补货点位**：无条件补满到最大库存
- **最低补货量**：调整后补货量不足20盒时，强制补到当前库存+20盒
- **库存扣减**：最终补货量需扣减点位当前库存

### 4.2 商品分配逻辑

#### 4.2.1 菜品评分计算
商品评分采用多层级回退机制：
1. **点位商品历史比重**：基于该点位该商品的历史销售比重
2. **点位最小比重**：该点位所有商品中第6高的比重
3. **商品平均比重**：该商品在所有点位的平均比重  
4. **全局平均比重**：所有商品的全局平均比重

#### 4.2.2 商品补货量计算
点位补货量 N
商品补货量 Mi = MAX(1, ROUND(点位补货量 × 商品评分占比))
注意!!!   其中商品为菜单内所有商品, 不是货车上的商品

模拟填货道:
1. 每个商品至少占用一个货道, 余 1 时不占用
2. 若有货道空余, 依次填补步骤 1 中的余 1
3. F = ∑Mi（所有商品补货量之和）, diff= N-F >0 时, 按商品补货量最小开始, 有空余货道空余加 1, 循环到diff 为 0
4. 比较库存货道占用, 若某商品的货道占用比预计多, 则优先从占用货道最多的商品中减1, 相同时减 Mi 小的
5. 各商品实际补货量 = MIN (当前货道商品的数量 Qi - 剩余库存, 0)



## 6. 业务规则与约束

### 6.1 特殊处理规则
- **新点位补满**：营业7天内的点位无条件补满
- **营销活动**：全量补货配置的点位补满
- **库存清理**：优先消耗临期商品
- **设备适配**：不同设备类型的容量差异化处理
