# 外卖点位 SKU 召回优化方案

## 一、核心优化方案


**现状分析：**
当前外卖平台存在"商品库存≤1时即显示售罄"的规则，导致部分仍有少量库存的SKU提前下线，影响点位商品供给丰富度。

**优化建议：**
将有效SKU的库存判定阈值由0调整为1。


## 二、深度优化方向

GRAB 的菜品曝光转换数据缺失, 导致点位菜品曝光转化率缺失, 这一块可以有策略取近似数据做评估
