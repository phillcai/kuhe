# 甜品分拣补货数学建模

## 一、核心参数定义

| 参数符号 | 含义说明 |
| ---- | ---- |
| $i$ | 甜品SKU标识（如sku1、sku2、sku3等） |
| $K$ | 点位总货道数 |
| $T$ | 货道类型数量 |
| $t_k$ | 第k个货道的类型，$t_k \in \{1, 2, ..., T\}$ |
| $S_i^{type}$ | SKU $i$ 对应的货道类型 |
| $L_i$ | 分配给SKU $i$ 的货道数量 |
| $C_i$ | SKU $i$ 的货道容量约束，$C_i = 5 \times L_i$（每个货道最多放5个相同SKU） |
| $G_i$ | 点位当前剩余SKU $i$ 的数量，$G = \sum G_i$ 为点位剩余总量 |
| $N_i$ | 仓库中SKU $i$ 的库存，$N = \sum N_i$ 为仓库总库存 |
| $S_i$ | SKU $i$ 补货后的最小数量（安全库存） |
| $M_i$ | 补货后SKU $i$ 的数量，$M_i = G_i + P_i$ |
| $P_i$ | SKU $i$ 的补货量（待求解），$\sum P_i = P$ |
| $r_i$ | SKU $i$ 的预期比例，满足 $\sum r_i = 1$ 且 $r_i \geq 0$ |
| $A_{i,t}$ | 兼容性矩阵，若SKU $i$ 可以放入类型$t$的货道则为1，否则为0 |
| $L_{t}^{total}$ | 类型$t$的总货道数，$\sum_{t=1}^{T} L_{t}^{total} = K$ |
| $L_{i,t}$ | 分配给SKU $i$ 的类型$t$货道数量 |
| $\mathbb{I}_{N_i \geq S_i - G_i}$ | 最小库存可满足指示函数，当仓库+当前库存满足最小需求时为1，否则为0 |
| $w_i$ | SKU $i$ 的重要性权重，用于安全库存惩罚计算 |
| $L_{i}^{current}$ | SKU $i$ 当前在点位已占用的货道数量，$L_{i}^{current} = \lceil \frac{G_i}{5} \rceil$ |

## 二、约束条件定义

### 2.1 强约束（硬约束）

| 约束类型 | 约束表达式 | 含义说明 |
| ---- | ---- | ---- |
| 仓库库存约束 | $P_i \leq N_i$ | 单SKU补货量不超过对应仓库库存 |
| 总库存约束 | $P = \sum P_i \leq N = \sum N_i$ | 总补货量不超过仓库总库存 |
| 货道容量约束 | $M_i \leq C_i = 5 \times L_i$ | 补货后数量不超过分配的货道容量 |
| 非负约束 | $P_i \geq 0$ | 不允许负补货 |
| 货道分配约束 | $L_i = \sum_{t=1}^{T} L_{i,t}$ | SKU $i$ 的总货道数等于各类型货道数之和 |
| 货道类型兼容约束 | $L_{i,t} > 0 \Rightarrow A_{i,t} = 1$ | 只能分配兼容类型的货道 |
| 货道数量约束 | $\sum_{i} L_{i,t} \leq L_{t}^{total}$ | 每种类型货道的分配总数不超过可用数量 |
| 总货道约束 | $\sum_{i} L_i = \sum_{i} \sum_{t} L_{i,t} \leq K$ | 分配的总货道数不超过点位总货道数 |
| 现有货道保持约束 | $L_i \geq L_{i}^{current}$ | 分配给SKU的货道数不能少于当前已占用的货道数 |

### 2.2 弱约束（软约束）

| 约束类型 | 目标函数/优先级 | 含义说明 |
| ---- | ---- | ---- |
| 最小库存约束 | $\max \sum_{i} \min(M_i, S_i) \cdot \mathbb{I}_{N_i \geq S_i - G_i}$ | 当仓库库存满足最小需求时优先满足安全库存，优先级：高 |
| 比例平衡约束 | $\min \sum_{i,j} \left\| \frac{M_i}{M_j} - \frac{r_i}{r_j} \right\| \times r_j$ | 补货后SKU数量比例接近预期比例，优先级：中 |
| 货道利用率约束 | $\max \frac{\sum_{i} L_i}{K}$ | 最大化货道利用率，尽可能填满所有货道，优先级：低 |

## 三、货道分配策略

### 3.1 货道兼容性映射

定义SKU与货道类型的兼容关系：
$$\text{Compatible}(i, t) = A_{i,t} = \begin{cases} 
1 & \text{if SKU } i \text{ 可以放入类型 } t \text{ 的货道} \\
0 & \text{otherwise}
\end{cases}$$

### 3.2 智能货道分配算法

**策略1：需求驱动分配（优先策略）**

1. **计算当前占用货道数**：
   $$L_{i}^{current} = \lceil \frac{G_i}{5} \rceil$$

2. **计算初始货道需求**：
   $$L_i^{demand} = \max\left(L_{i}^{current}, \lceil \frac{\max(S_i, G_i + r_i \times P_{target})}{5} \rceil\right)$$
   其中 $P_{target}$ 为目标总补货量。

3. **按兼容性筛选可用货道**：
   $$L_i^{available} = \sum_{t: A_{i,t}=1} L_{t}^{total}$$

4. **分配货道**：
   $$L_i = \min(L_i^{demand}, L_i^{available})$$
   确保 $L_i \geq L_{i}^{current}$

**策略2：比例分配（回退策略）**

当需求驱动分配无法满足总货道约束时：

1. **预先分配现有货道**：
   $$K_{reserved} = \sum_{i} L_{i}^{current}$$
   $$K_{remaining} = K - K_{reserved}$$

2. **计算调整后比例**：
   对于无兼容货道的SKU，将其比例重新分配：
   $$r_i^{adjusted} = \frac{r_i}{1 - \sum_{j: L_j^{available}=0} r_j}$$

3. **按调整后比例分配剩余货道**：
   $$L_i^{additional} = \text{round}(r_i^{adjusted} \times K_{remaining})$$
   $$L_i = L_{i}^{current} + L_i^{additional}$$
   确保 $L_i \geq L_{i}^{current}$

## 四、优化目标函数

分层优化策略，按优先级依次处理：

### 4.1 第一层：最小库存优先满足
$$\max \quad F_{safety} = \sum_{i} \min(M_i, S_i) \cdot \mathbb{I}_{N_i \geq S_i - G_i}$$

其中 $\mathbb{I}_{N_i \geq S_i - G_i}$ 为指示函数：
$$\mathbb{I}_{N_i \geq S_i - G_i} = \begin{cases} 
1 & \text{if } N_i + G_i \geq S_i \text{（仓库+当前库存满足最小需求）} \\
0 & \text{otherwise}
\end{cases}$$

### 4.2 第二层：综合优化目标
在满足最小库存约束的基础上，进行多目标优化：

$$\min \quad F = \alpha \cdot F_{proportion} + \beta \cdot F_{utilization} + \gamma \cdot F_{safety\_penalty}$$

其中：
- $F_{proportion} = \sum_{i,j} \left| \frac{M_i}{M_j} - \frac{r_i}{r_j} \right| \times r_j$ （比例偏差项）
- $F_{utilization} = K - \sum_{i} L_i$ （未利用货道数）
- $F_{safety\_penalty} = \sum_{i} \max(0, S_i - M_i) \cdot w_i$ （未满足安全库存的惩罚项）
- $w_i$ 为SKU $i$ 的重要性权重
- $\alpha, \beta, \gamma$ 为权重系数，建议 $\alpha = 0.5, \beta = 0.2, \gamma = 0.3$

## 五、算法执行步骤

### 步骤1：货道兼容性分析
1. 构建兼容性矩阵 $A_{i,t}$
2. 计算每个SKU当前占用货道数：$L_{i}^{current} = \lceil \frac{G_i}{5} \rceil$
3. 计算每个SKU的可用货道总数 $L_i^{available}$
4. 识别无兼容货道的SKU并处理其比例重分配

### 步骤2：初始货道分配
1. **保证现有货道约束**：
   首先为每个SKU分配至少 $L_{i}^{current}$ 个货道
2. **需求驱动分配策略**：
   在满足现有货道约束基础上，应用需求驱动分配
   $$L_i^{demand} = \max\left(L_{i}^{current}, \lceil \frac{\max(S_i, G_i + r_i \times P_{target})}{5} \rceil\right)$$
3. 验证总货道约束，必要时回退到比例分配
4. 计算每个SKU的货道容量 $C_i = 5 \times L_i$

### 步骤3：最小库存优先处理
1. **识别可满足最小库存的SKU**：
   对于每个SKU $i$，检查 $N_i + G_i \geq S_i$
2. **优先分配最小库存**：
   对于可满足的SKU，设置：$M_i^{min} = \max(S_i, G_i)$
   对应补货量：$P_i^{min} = \max(0, S_i - G_i)$
3. **计算剩余可用资源**：
   - 剩余仓库库存：$N_i^{remain} = N_i - P_i^{min}$
   - 剩余货道容量：$C_i^{remain} = C_i - M_i^{min}$

### 步骤4：比例平衡补货量计算
1. 基于预期比例计算理想补货后数量：$M_i^{ideal} = r_i \times M_{total}$
2. 应用约束条件：
   - 货道容量约束：$M_i \leq C_i$
   - 已分配最小库存：$M_i \geq M_i^{min}$
   - 剩余仓库库存约束：$P_i - P_i^{min} \leq N_i^{remain}$
3. 计算最终补货量：$P_i = M_i - G_i$

### 步骤5：动态调整优化
1. 计算当前分配的比例偏差
2. 寻找改善机会（在不违背最小库存优先原则下）：
   - 货道重新分配
   - 补货量微调
3. 迭代优化直到收敛或达到最大迭代次数

### 步骤6：结果验证
1. 验证所有强约束是否满足
2. 检查最小库存优先满足情况
3. 计算货道利用率和比例偏差
4. 输出最终分配方案

## 六、实例应用

### 6.1 场景设置
假设有3种类型货道，5个甜品SKU：

| SKU | 兼容货道类型 | 预期比例 | 当前库存 | 仓库库存 | 最小库存 | 当前占用货道 |
|-----|------------|----------|----------|----------|----------|-------------|
| A   | {1, 2}     | 0.3      | 2        | 15       | 3        | 1           |
| B   | {1}        | 0.25     | 1        | 12       | 2        | 1           |
| C   | {2, 3}     | 0.2      | 0        | 10       | 1        | 0           |
| D   | {3}        | 0.15     | 3        | 8        | 2        | 1           |
| E   | {1, 2, 3}  | 0.1      | 1        | 5        | 1        | 1           |

货道配置：类型1有8个货道，类型2有6个货道，类型3有4个货道，总计18个货道。

当前占用货道计算：$L_{i}^{current} = \lceil \frac{G_i}{5} \rceil$
- SKU A: $\lceil \frac{2}{5} \rceil = 1$
- SKU B: $\lceil \frac{1}{5} \rceil = 1$  
- SKU C: $\lceil \frac{0}{5} \rceil = 0$
- SKU D: $\lceil \frac{3}{5} \rceil = 1$
- SKU E: $\lceil \frac{1}{5} \rceil = 1$

当前已占用货道总数：$K_{reserved} = 1+1+0+1+1 = 4$个，剩余可分配货道：$K_{remaining} = 18-4 = 14$个。

### 6.2 求解过程
按照上述算法步骤求解，得到最优的货道分配和补货方案。
