# CK分拣数学建模

## 一、问题描述

仓库里有不同SKU的货物，需要把货物分拣到车辆上。分拣过程需要满足以下要求：

1. **尽量满足分拣数量要求**：目标分拣总量为 $M$
2. **车辆货架约束**：车辆有 $n$ 层货架，每层只能放同一个SKU的货，每层最多放 9 个，车辆最大容量为 $9 \times n$
3. **比例平衡要求**：分拣到车上的SKU比例要尽可能和仓库的SKU比例接近，避免仓库剩余SKU数量不均衡
4. **单SKU上限约束**：每个SKU的分拣数量不能超过 $M$ 的 $p=20\%$，即每个SKU最多分拣 $p \times M = 0.2M$ 个
5. **全SKU包含约束**：每次分拣必须包含所有SKU，即每个SKU的分拣数量 $x_i \geq 1$，$\forall i$

## 二、核心参数定义

| 参数符号 | 含义说明 |
| ---- | ---- |
| $i$ | SKU标识（$i = 1, 2, ..., I$，共 $I$ 种SKU） |
| $M$ | 目标分拣总量（待分拣到车辆上的货物总数） |
| $n$ | 车辆货架层数 |
| $C_{max}$ | 车辆最大容量，$C_{max} = 9 \times n$ |
| $p$ | 单SKU分拣上限比例，$p = 0.2$（20%） |
| $N_i$ | 仓库中SKU $i$ 的库存数量，$N = \sum_{i=1}^{I} N_i$ 为仓库总库存 |
| $r_i$ | 仓库中SKU $i$ 的比例，$r_i = \frac{N_i}{N}$，满足 $\sum_{i=1}^{I} r_i = 1$ 且 $r_i \geq 0$ |
| $x_i$ | SKU $i$ 的分拣数量（决策变量，待求解），$x_i \geq 0$ 且为整数 |
| $X$ | 实际分拣总量，$X = \sum_{i=1}^{I} x_i$ |
| $y_{i,j}$ | 二进制变量，表示SKU $i$ 是否占用第 $j$ 层货架（$j = 1, 2, ..., n$） |
| $L_i$ | SKU $i$ 占用的货架层数，$L_i = \sum_{j=1}^{n} y_{i,j}$ |

## 三、约束条件

### 3.1 强约束（硬约束）

| 约束类型 | 约束表达式 | 含义说明 |
| ---- | ---- | ---- |
| **车辆容量约束** | $X = \sum_{i=1}^{I} x_i \leq C_{max} = 9n$ | 实际分拣总量不超过车辆最大容量 |
| **仓库库存约束** | $x_i \leq N_i$ | 每个SKU的分拣数量不超过仓库库存 |
| **单SKU上限约束** | $x_i \leq p \times M = 0.2M$ | 每个SKU的分拣数量不超过目标总量的20% |
| **货架层数约束** | $L_i = \lceil \frac{x_i}{9} \rceil$ | SKU $i$ 占用的层数等于其分拣数量除以9向上取整 |
| **总层数约束** | $\sum_{i=1}^{I} L_i \leq n$ | 所有SKU占用的总层数不超过车辆总层数 |
| **每层单一SKU约束** | $x_i \leq 9 \times L_i$ | 每个SKU的分拣数量不超过其占用层数乘以9 |
| **非负整数约束** | $x_i \geq 0$ 且 $x_i \in \mathbb{Z}$ | 分拣数量必须为非负整数 |
| **全SKU包含约束** | $x_i \geq 1, \forall i$ | 每个SKU的分拣数量至少为1，确保所有SKU都被包含 |
| **货架分配约束** | $\sum_{i=1}^{I} y_{i,j} \leq 1, \forall j$ | 每层货架最多只能分配给一个SKU |

### 3.2 弱约束（软约束）

| 约束类型 | 目标函数/优先级 | 含义说明 |
| ---- | ---- | ---- |
| **目标总量约束** | $\min |X - M|$ | 尽量接近目标分拣总量 $M$，优先级：高 |
| **比例平衡约束** | $\min \sum_{i=1}^{I} \left| \frac{x_i}{X} - r_i \right|$ | 分拣后SKU比例接近仓库SKU比例，优先级：中 |
| **货架利用率约束** | $\max \frac{X}{C_{max}}$ | 最大化车辆货架利用率，优先级：低 |

## 四、优化目标函数

采用分层优化策略，按优先级依次处理：

### 4.1 第一层：目标总量优先

$$\min \quad F_{target} = |X - M| = \left| \sum_{i=1}^{I} x_i - M \right|$$

优先使实际分拣总量 $X$ 尽可能接近目标总量 $M$。

### 4.2 第二层：综合优化目标

在满足目标总量约束的基础上，进行多目标优化：

$$\min \quad F = \alpha \cdot F_{proportion} + \beta \cdot F_{target\_penalty} + \gamma \cdot F_{utilization}$$

其中：

- **比例偏差项**：
  $$F_{proportion} = \sum_{i=1}^{I} \left| \frac{x_i}{X} - r_i \right| \times r_i$$
  衡量分拣后SKU比例与仓库SKU比例的偏差，权重为 $r_i$（比例越大的SKU偏差权重越大）

- **目标总量惩罚项**：
  $$F_{target\_penalty} = \max(0, M - X)$$
  当实际分拣量小于目标量时的惩罚

- **货架利用率项**：
  $$F_{utilization} = 1 - \frac{X}{C_{max}} = 1 - \frac{X}{9n}$$
  衡量货架利用率，值越小表示利用率越高

- **权重系数**：建议 $\alpha = 0.6, \beta = 0.3, \gamma = 0.1$

## 五、算法设计

### 5.1 算法步骤

#### 步骤1：参数初始化与约束检查

1. **检查可行性**：
   - 检查仓库总库存是否满足目标：$N = \sum_{i=1}^{I} N_i \geq M$
   - 检查车辆容量是否满足：$C_{max} = 9n \geq M$
   - 如果 $N < M$，则调整目标：$M_{actual} = \min(M, N)$
   - 如果 $C_{max} < M$，则调整目标：$M_{actual} = \min(M, C_{max})$

2. **计算仓库SKU比例**：
   $$r_i = \frac{N_i}{N}, \quad \forall i$$

3. **计算单SKU上限**：
   $$x_i^{max} = \min(N_i, 0.2M, 9n)$$

4. **检查全SKU包含可行性**：
   - 检查每个SKU是否有库存：$N_i \geq 1, \forall i$
   - 如果存在 $N_i = 0$ 的SKU，则无法满足全SKU包含约束，需要调整问题设置
   - 检查最小分拣总量：$M_{min} = I$（至少需要分拣 $I$ 个，每个SKU至少1个）
   - 如果 $M < I$，则调整目标：$M_{actual} = \max(M, I)$

#### 步骤2：初始分拣量计算（基于比例）

1. **计算理想分拣量**（不考虑约束）：
   $$x_i^{ideal} = r_i \times M, \quad \forall i$$

2. **应用单SKU上限约束**：
   $$x_i^{temp} = \min(x_i^{ideal}, x_i^{max}), \quad \forall i$$

3. **应用仓库库存约束**：
   $$x_i^{temp} = \min(x_i^{temp}, N_i), \quad \forall i$$

4. **应用全SKU包含约束**：
   $$x_i^{temp} = \max(x_i^{temp}, 1), \quad \forall i$$
   确保每个SKU至少分拣1个

5. **取整处理**：
   $$x_i^{temp} = \text{round}(x_i^{temp}), \quad \forall i$$
   取整后再次确保全SKU包含：$x_i^{temp} = \max(\text{round}(x_i^{temp}), 1), \forall i$

#### 步骤3：货架层数分配

1. **计算所需层数**：
   $$L_i = \lceil \frac{x_i^{temp}}{9} \rceil, \quad \forall i$$

2. **检查总层数约束**：
   - 如果 $\sum_{i=1}^{I} L_i \leq n$，则继续
   - 如果 $\sum_{i=1}^{I} L_i > n$，则需要调整分拣量

3. **层数超限处理**：
   当总层数超过 $n$ 时，按以下策略调整：
   - 计算层数缺口：$\Delta L = \sum_{i=1}^{I} L_i - n$
   - 按比例减少各SKU的层数，或优先减少比例偏差小的SKU的层数
   - 重新计算分拣量：$x_i^{temp} = \min(x_i^{temp}, 9 \times L_i^{new})$

#### 步骤4：目标总量调整

计算当前分拣总量：
$$X^{temp} = \sum_{i=1}^{I} x_i^{temp}$$

**情况1：$X^{temp} < M$（存在缺口）**

缺口：$D = M - X^{temp}$

调整策略：
1. **识别可增加SKU**：满足 $x_i^{temp} < x_i^{max}$ 且 $L_i < \lceil \frac{x_i^{max}}{9} \rceil$ 或 $\sum_{i=1}^{I} L_i < n$
2. **计算改善得分**：对于每个可增加SKU $i$，计算增加1个单位后对比例偏差的改善：
   $$\text{改善得分}_i = F_{proportion}^{current} - F_{proportion}^{after\_increase}$$
3. **按改善得分排序**：优先增加改善得分高的SKU
4. **逐个增加**：每次增加1个单位，直到缺口补足或无可增加SKU

**情况2：$X^{temp} > M$（存在超额）**

超额：$E = X^{temp} - M$

调整策略：
1. **识别可减少SKU**：满足 $x_i^{temp} > 1$（必须大于1，因为全SKU包含约束要求 $x_i \geq 1$）
2. **计算改善得分**：对于每个可减少SKU $i$，计算减少1个单位后对比例偏差的改善：
   $$\text{改善得分}_i = F_{proportion}^{current} - F_{proportion}^{after\_decrease}$$
3. **按改善得分排序**：优先减少改善得分高的SKU
4. **逐个减少**：每次减少1个单位，直到超额消除或达到最小约束（$x_i^{temp} \geq 1$）

**情况3：$X^{temp} = M$（正好满足）**

无需调整，直接进入下一步。

#### 步骤5：货架利用率优化

在满足目标总量和比例平衡的基础上，尝试提高货架利用率：

1. **识别空余层数**：
   $$L_{empty} = n - \sum_{i=1}^{I} L_i$$

2. **寻找可扩展SKU**：
   - 满足 $x_i < x_i^{max}$ 且 $L_i < \lceil \frac{x_i^{max}}{9} \rceil$
   - 计算扩展潜力：$\Delta x_i = \min(x_i^{max} - x_i, 9 \times L_{empty})$

3. **按比例平衡优先级分配**：
   - 优先分配给实际比例低于预期比例（$\frac{x_i}{X} < r_i$）的SKU
   - 逐个分配空余层数，每次分配1层，增加最多9个单位的该SKU

#### 步骤6：最终验证与输出

1. **验证所有强约束**：
   - ✓ $X = \sum_{i=1}^{I} x_i \leq 9n$
   - ✓ $x_i \leq N_i, \forall i$
   - ✓ $x_i \leq 0.2M, \forall i$
   - ✓ $x_i \geq 1, \forall i$（全SKU包含约束）
   - ✓ $\sum_{i=1}^{I} L_i \leq n$
   - ✓ $x_i \leq 9 \times L_i, \forall i$

2. **计算优化指标**：
   - 目标达成率：$\frac{X}{M} \times 100\%$
   - 比例偏差：$F_{proportion} = \sum_{i=1}^{I} \left| \frac{x_i}{X} - r_i \right| \times r_i$
   - 货架利用率：$\frac{X}{9n} \times 100\%$

3. **输出最终方案**：
   - 各SKU分拣数量：$x_i, \forall i$
   - 各SKU占用层数：$L_i, \forall i$
   - 实际分拣总量：$X$
   - 优化指标值

## 六、实例应用

### 6.1 场景设置

假设：
- 目标分拣总量：$M = 100$
- 车辆货架层数：$n = 15$（最大容量 $9 \times 15 = 135$）
- 单SKU上限比例：$p = 0.2$（每个SKU最多分拣 $0.2 \times 100 = 20$ 个）
- 仓库有5种SKU，库存和比例如下：

| SKU | 仓库库存 $N_i$ | 仓库比例 $r_i$ | 单SKU上限 $x_i^{max}$ |
|-----|:-------------:|:-------------:|:-------------------:|
| A   | 50            | 0.4           | 20                  |
| B   | 30            | 0.24          | 20                  |
| C   | 25            | 0.2           | 20                  |
| D   | 15            | 0.12          | 20                  |
| E   | 5             | 0.04          | 20                  |

仓库总库存：$N = 125$

### 6.2 求解过程

**步骤1：参数初始化**
- 仓库总库存 $N = 125 \geq M = 100$ ✓
- 车辆容量 $C_{max} = 135 \geq M = 100$ ✓
- 全SKU包含可行性检查：所有SKU都有库存（$N_i \geq 1, \forall i$）✓
- 最小分拣总量：$M_{min} = I = 5 \leq M = 100$ ✓
- 各SKU上限：$x_i^{max} = \min(N_i, 20) = \{20, 20, 20, 15, 5\}$

**步骤2：初始分拣量计算**
- 理想分拣量：$x_i^{ideal} = \{40, 24, 20, 12, 4\}$
- 应用上限约束：$x_i^{temp} = \{20, 20, 20, 12, 4\}$（SKU A、B、C受上限约束）
- 应用全SKU包含约束：$x_i^{temp} = \max(\{20, 20, 20, 12, 4\}, 1) = \{20, 20, 20, 12, 4\}$（所有SKU都已满足 $\geq 1$）
- 取整后：$x_i^{temp} = \{20, 20, 20, 12, 4\}$
- 当前总量：$X^{temp} = 76$

**步骤3：货架层数分配**
- 所需层数：$L_i = \{\lceil 20/9 \rceil, \lceil 20/9 \rceil, \lceil 20/9 \rceil, \lceil 12/9 \rceil, \lceil 4/9 \rceil\} = \{3, 3, 3, 2, 1\}$
- 总层数：$\sum L_i = 12 \leq 15$ ✓

**步骤4：目标总量调整**
- 缺口：$D = 100 - 76 = 24$
- 可增加SKU：A、B、C（已到上限20，无法增加）、D（可从12增加到15）、E（可从4增加到5）
- 由于A、B、C已到上限，优先增加D和E
- 调整后：$x_i = \{20, 20, 20, 15, 5\}$，总量 $X = 80$
- 仍有缺口 $D = 20$，但A、B、C已到上限，D、E也已到上限，无法继续增加
- **结果**：实际分拣总量 $X = 80$，未达到目标 $M = 100$（受单SKU上限约束限制）

**步骤5：货架利用率优化**
- 当前占用层数：$\sum L_i = 12$
- 空余层数：$L_{empty} = 15 - 12 = 3$
- 由于各SKU都已达到上限，无法进一步扩展

**步骤6：最终结果**

| SKU | 分拣数量 $x_i$ | 占用层数 $L_i$ | 实际比例 $\frac{x_i}{X}$ | 预期比例 $r_i$ | 比例偏差 |
|-----|:------------:|:------------:|:---------------------:|:------------:|:------:|
| A   | 20           | 3            | 0.25                  | 0.4          | 0.15   |
| B   | 20           | 3            | 0.25                  | 0.24         | 0.01   |
| C   | 20           | 3            | 0.25                  | 0.2          | 0.05   |
| D   | 15           | 2            | 0.1875                | 0.12         | 0.0675 |
| E   | 5            | 1            | 0.0625                | 0.04         | 0.0225 |

- **实际分拣总量**：$X = 80$
- **目标达成率**：$\frac{80}{100} = 80\%$
- **总比例偏差**：$F_{proportion} = 0.15 \times 0.4 + 0.01 \times 0.24 + 0.05 \times 0.2 + 0.0675 \times 0.12 + 0.0225 \times 0.04 = 0.0815$
- **货架利用率**：$\frac{80}{135} = 59.3\%$
- **空余层数**：3层

### 6.3 结果分析

由于单SKU上限约束（$p = 0.2$）的限制，SKU A、B、C的分拣数量都被限制在20个，导致：
1. **目标总量未完全达成**：实际分拣80个，距离目标100个还差20个
2. **比例偏差较大**：SKU A的实际比例（0.25）远低于预期比例（0.4）
3. **货架利用率较低**：仅使用了12层货架，还有3层空余

**改进建议**：
- 如果允许，可以适当放宽单SKU上限比例 $p$，例如从0.2调整到0.3
- 或者调整目标总量 $M$，使其更符合实际约束条件

## 七、算法特点

### 7.1 优势

1. **多约束平衡**：同时考虑车辆容量、仓库库存、单SKU上限、货架层数等多重约束
2. **比例平衡优化**：通过改善得分机制，优先调整能最大程度改善比例偏差的SKU
3. **分层优化策略**：先满足目标总量，再优化比例平衡，最后提高利用率
4. **货架资源管理**：智能分配货架层数，最大化空间利用

### 7.2 局限性

1. **单SKU上限约束可能过严**：当 $p \times M$ 较小时，可能无法达到目标总量
2. **全SKU包含约束的限制**：当SKU种类 $I$ 较多时，最小分拣总量为 $I$，可能影响目标总量的达成
3. **整数约束**：分拣数量必须为整数，可能导致无法完全达到理想比例
4. **计算复杂度**：当SKU种类较多时，优化计算量较大

### 7.3 适用场景

- 仓库SKU种类较多（$I \geq 5$）
- 需要保持分拣后SKU比例与仓库比例接近
- 车辆容量和货架层数有限
- 对单SKU分拣量有上限要求
- **要求每次分拣必须包含所有SKU**（全SKU包含约束）

## 八、扩展与改进

### 8.1 动态调整单SKU上限

根据仓库SKU比例动态调整单SKU上限：
$$x_i^{max} = \min(N_i, \max(p \times M, r_i \times M \times \alpha), 9n)$$
其中 $\alpha \geq 1$ 为调整系数，允许比例大的SKU有更高的上限。

### 8.2 多车辆协同分拣

当单辆车无法满足目标总量时，可以考虑多辆车协同：
- 将目标总量 $M$ 分配到多辆车
- 每辆车独立优化，但需要考虑整体比例平衡
- 协调各车的分拣方案，使整体比例接近仓库比例

### 8.3 考虑分拣成本

在优化目标中加入分拣成本因素：
- 不同SKU的分拣难度不同
- 优先分拣成本低的SKU
- 在比例平衡和成本之间权衡
