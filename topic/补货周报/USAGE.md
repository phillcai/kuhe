# 补货周报 - 快速使用指南

## 🚀 快速开始

### 方法一: 使用启动脚本(最简单)

```bash
cd topic/补货周报
./run.sh
```

脚本会:
1. 自动查询所有数据
2. 生成 HTML 报告
3. 询问是否在浏览器中打开

### 方法二: 手动运行

```bash
# 在项目根目录
uv run topic/补货周报/generate_report.py
```

## 📊 生成的报告包含

### 1. 周日均补货数统计
- 周数 (周日日期)
- 补货数 (周总数)
- 日均补货
- 日最大补货数
- 日均点位

### 2. 周满足率统计
- 日期 (周日日期)
- 全部 (所有车辆平均满足率)
- 正常车 (车辆ID: 2, 14, 15)
- 虚拟车 (其他车辆)

### 3. 周缺货率统计
- 周起始日 (周日)
- 缺货率(sku权重)
- session数

## 📁 输出文件

- **report.html** - 主报告文件
- 每个脚本单独运行时还会生成对应的Excel文件

## ⚙️ 配置要求

### 数据库连接
确保 `code/lib/db_connection.py` 中配置了正确的数据库连接信息。

### Python环境
项目使用 `uv` 管理依赖,首次运行前需要:

```bash
cd /path/to/kuhe
uv sync
```

## 🔧 常见问题

### Q: 报告中没有数据?
A: 检查数据库中是否有最近90天的数据。

### Q: 数据库连接失败?
A: 检查网络连接和数据库配置。

### Q: 依赖包缺失?
A: 运行 `uv sync` 重新安装依赖。

## 📅 使用建议

- **频率**: 建议每周一生成上周的周报
- **归档**: 可将历史报告重命名保存,如 `report_20251118.html`
- **分享**: HTML文件可直接发送给相关人员查看

## 📝 单独查询某项数据

如果只需要某一项数据:

```bash
# 只查询缺货率
uv run topic/补货周报/query_weekly_shortage.py

# 只查询满足率
uv run topic/补货周报/query_weekly_satisfaction.py

# 只查询补货数
uv run topic/补货周报/query_weekly_replenishment.py
```

每个脚本会:
- 在终端显示统计数据
- 导出Excel文件到当前目录

## 💡 提示

- HTML报告可在任何现代浏览器中打开
- 报告支持移动设备浏览
- 表格数据可以直接从浏览器复制到Excel
