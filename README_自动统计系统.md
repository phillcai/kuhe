# 自评估Excel自动统计系统使用说明

## 🎯 系统概述

这是一个自动化的Excel统计系统，能够实时监控自评估Excel文件的变化，并自动更新按天赋类型统计的得分数据。

## 📁 文件说明

- `auto_statistics.py` - 自动统计系统主程序
- `自评估_修改版.xlsx` - 包含评估数据和统计表格的Excel文件

## 🚀 功能特性

### 1. 自动数据统计
- 按天赋类型统计得分情况
- 计算题目数量、总得分、平均得分、得分率等指标
- 生成可视化图表

### 2. 实时监控
- 检测Excel文件变化
- 自动重新计算统计数据
- 更新统计表格和图表

### 3. 数据验证
- 自动计算得分（经常=2分，偶尔=1分，很少=0分）
- 过滤无效数据
- 确保数据完整性

## 📊 统计指标

### 天赋类型（6种）
1. **W - Wonder（洞察）** - 3题
2. **I - Invention（创意）** - 3题  
3. **D - Discernment（判断）** - 3题
4. **G - Galvanizing（动员）** - 3题
5. **E - Enablement（使能）** - 3题
6. **T - Tenacity（交付）** - 3题

**总计：18题，最高可能得分36分**

### 统计指标
- **题目数量**：每个天赋类型的题目数
- **总得分**：该天赋类型获得的总分数
- **平均得分**：该天赋类型的平均分数
- **最高可能得分**：该天赋类型的最高可能分数
- **得分率(%)**：得分率 = 总得分 / 最高可能得分 × 100%

## 🛠️ 使用方法

### 运行自动统计系统

```bash
python auto_statistics.py
```

### 操作选项

1. **运行一次统计更新**
   - 立即执行一次统计计算和更新
   - 适用于手动触发统计更新

2. **开始监控模式**
   - 持续监控Excel文件变化
   - 检测到变化时自动更新统计
   - 可设置检查间隔（默认5秒）
   - 按Ctrl+C停止监控

3. **添加自动计算公式**
   - 在Excel中添加自动计算公式
   - 使得分列能够自动计算

## 🎨 Excel文件结构

### 主工作表
- **天赋类型**：6种天赋类型
- **评估条目**：18个评估问题
- **经常（2分）**：选择"是"得2分
- **偶尔（1分）**：选择"是"得1分
- **很少（0分）**：选择"是"得0分
- **得分**：自动计算的得分

### 统计工作表
- **天赋类型统计表**：按天赋类型汇总的统计数据
- **得分率对比图表**：可视化各天赋类型表现
- **总计行**：整体统计信息
- **使用说明**：详细的操作说明

## 🔧 技术特性

### 自动化功能
- **文件监控**：使用MD5哈希检测文件变化
- **数据验证**：自动过滤无效数据
- **公式计算**：自动计算得分和统计指标
- **图表更新**：自动更新可视化图表

### 错误处理
- **除零保护**：避免除零错误
- **数据验证**：确保数据完整性
- **异常捕获**：友好的错误提示

## 📝 使用建议

### 日常使用
1. 打开Excel文件填写评估
2. 运行监控模式自动更新统计
3. 查看统计工作表了解各天赋类型表现

### 批量处理
1. 填写完所有评估后
2. 运行一次统计更新
3. 查看最终统计结果

### 数据维护
1. 定期备份Excel文件
2. 确保数据格式正确
3. 及时处理异常数据

## ⚠️ 注意事项

1. **数据格式**：确保选择项为"是"或"否"
2. **文件路径**：确保Excel文件路径正确
3. **权限问题**：确保有文件读写权限
4. **Excel版本**：建议使用Excel 2016或更高版本

## 🆘 故障排除

### 常见问题

1. **文件不存在**
   - 检查文件路径是否正确
   - 确保文件存在且可访问

2. **数据读取错误**
   - 检查Excel文件格式
   - 确保列名正确

3. **统计结果异常**
   - 检查数据完整性
   - 重新运行统计更新

4. **监控模式不工作**
   - 检查文件权限
   - 确保文件未被其他程序占用
